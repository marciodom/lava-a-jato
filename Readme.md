🚗 Lava a Jato — Sistema de Gestão para Lava-Rápido (PWA)
Aplicação Web desenvolvida como Progressive Web App (PWA) para auxiliar no gerenciamento de atendimentos em empresas de lavagem automotiva, conhecidas popularmente como lava-jato ou lava a jato.
O sistema permite registrar serviços realizados, gerar recibos para clientes, enviar rapidamente via WhatsApp e gerar relatórios de atividades do dia.
A aplicação funciona diretamente no navegador e também pode ser instalada no celular como um aplicativo, sem necessidade de lojas de aplicativos.

🎯 Funcionalidades
• Registro de atendimento de clientes
• Controle automático de número de atendimento (ticket)
• Cadastro de cliente, telefone, veículo e valor do serviço
• Geração automática de recibo em imagem
• Download do recibo diretamente no celular
• Integração com WhatsApp para envio ao cliente
• Armazenamento local dos registros do dia
• Geração de relatório completo de atividades
• Cálculo automático do valor total arrecadado
• Interface otimizada para celular
• Sistema de notificações (toast)
• Tutorial de uso integrado
• Personalização de logo e nome da empresa
• Instalação como Aplicativo PWA

📲 Instalação como Aplicativo
O sistema pode ser instalado diretamente no celular.
Passos:
Acesse o site no navegador
Aguarde aparecer a opção Instalar Aplicativo
Toque em Instalar
O app será adicionado à tela inicial do celular
Após instalado, o sistema funciona como um aplicativo nativo.
📊 Funcionamento do Sistema

1️⃣ Registrar dados do cliente
